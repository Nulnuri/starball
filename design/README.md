# 화면 시안

앱을 만들기 전에 그린 목업입니다. 실제 구현은 `../web/` 에 있고,
이 폴더는 설계 기록으로만 남겨둡니다.

```
Main.dc.html        1 · 오늘        입력할 세 값
Reasoning.dc.html   2 · 근거        선발·구장·불펜·최근 페이스
History.dc.html     3 · 기록        지난 추천 vs 실제, 스타볼 진행도
LockScreen.dc.html  4 · 잠금화면     ntfy 알림 비교용
canvas.json         배치 정보
```

당시 시안과 실제 구현의 차이:

- 문항이 9개 추정 → 실제 3개(승패·득실차·홈런)로 확정되면서 미션 카드가 줄었습니다
- 득실차·홈런이 구간이 아니라 0~10 정확값으로 밝혀져 확률이 크게 낮아졌습니다
- `근거` 화면 맨 위에 **문항별 신뢰도**가 추가됐습니다 (시안에는 없던 것)

`.dc.html` 은 Claude Design 캔버스 형식입니다. 그냥 열어보려면 브라우저가
아니라 캔버스 편집기가 필요하고, 형식 자체는 참고용으로만 두었습니다.
실제 화면은 배포된 앱에서 바로 확인하는 게 정확합니다.
